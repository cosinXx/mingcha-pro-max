# 证据分级与引用纪律（Evidence & Citation）

## 1. 三级证据分级

| 级别 | 定义 | 使用规则 |
|------|------|----------|
| 一级 | 官方披露、权威数据库、原始文献、财报/招股书、一手数据 | 可直接陈述，作为展示数值 |
| 二级 | 具名机构（券商/咨询/研究机构）、主流媒体、知名行业网站 | 须显名归因："据××报告""××媒体报道" |
| 三级 | 传闻、社交网络、匿名来源、单方说法、二手转述 | 仅作线索，不入正文展示，最多在注脚提示"存在该说法" |

**结论强度不超出证据档位**：一级才敢下确定判断；二级只作趋势性判断；三级不撑任何结论。

## 2. 来源台账登记格式（检索时同步记录，不落本地盘）

每条证据登记一行，字段：

```
来源标识 | URL | 标题/机构 | 可信度级别 | 数据基期 | 原文数字+单位+口径 | 正文角色（展示/线索） | 备注
```

- 原文数字**照抄**，不换算不四舍五入；换算与测算单独标注"本研究测算"。
- 两条取数通道：公开检索（general_search / 专用搜索）与金融数据（seed_finance_search 等专业库）；新闻里的数字只作线索。

## 3. 引用纪律

- 引用编号不预分配：正文成稿时按**读者首次遇到该来源的顺序**从 `[1]` 递增分配，同一来源全文复用同一编号，句末标注。
- 改稿导致来源提前/延后时，同步重排编号与文末参考文献，杜绝 `[1][4][2][3]` 式错乱。
- 文末参考文献必须可点击、与正文编号一一勾稽。

## 4. 措辞表

| 情形 | 写法 |
|------|------|
| 一级来源支撑 | 直接陈述事实 |
| 二级来源支撑 | "据××（机构名）测算/报告" |
| 媒体观点 | "据报道" |
| 本研究推断 | "这可能意味着……，需后续数据验证" |
| 数据缺口 | "公开信息有限，无法确认" |
| 多方矛盾 | 并列列出各方口径 + 分析差异原因，不偏信一方 |

## 5. 六维核对（每个数字写入正文前）

1. 来源 URL 存在且可访问？
2. 可信度级别与措辞匹配？
3. 数字与台账源值一致（不漂移）？
4. 基期标注清楚（哪年/哪季度）？
5. 单位与口径正确（% / 亿元 / 同比 / 环比）？
6. 上下文引用编号正确且连续？
