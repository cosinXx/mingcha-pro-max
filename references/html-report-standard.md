# HTML 网页研报规范（HTML Report Standard）

生成 HTML 研报前**必须**先完整 Read `html` Skill 的 SKILL.md，遵守其全部硬规则（单文件自包含、内联 CSS/JS、外部库走 jsDelivr、响应式、shot.py 自检、交付用 present_files）。本文档只补充研报专属要求。

## 1. 文件与结构

- 在工作区建语义化目录，如 `output/deep-research-html/`，产物为**一个自包含的** `index.html`（CSS 内联 `<style>`、JS 内联 `<script>`，不拆文件）。
- 页面结构（自上而下）：
  1. **封面区**：主题名、副标题（核心判断一句话）、研究基准年、作者标识"多专家联合研究"。
  2. **目录导航**：锚点导航或页内 hash 路由；桌面端可做固定侧边栏，移动端折叠。
  3. **执行摘要**：核心判断、共识 vs 非共识、三情景速览（乐观/基准/悲观）。
  4. **维度章节**：每个子命题一章，先亮判断再给证据；章节内嵌图表。
  5. **交叉验证与争议**：多源互证、矛盾点、Red Team 反方观点（折叠面板展示）。
  6. **风险与证伪信号**：风险清单 + "什么信号出现就推翻主线"。
  7. **来源清单**：编号 + 标题 + 可点击 URL，与正文引用 `[n]` 勾稽。
  8. **研究过程**（可折叠）：研究窗口、检索范围、数据缺口声明。

## 2. 可视化

- 趋势、占比、比较、分布、流程、机制、架构等结构化关系**必须用图表承载**（遵循 `doubao-visualization` Skill 规范），不止用文字。
- 图表库统一用 **ECharts**，经 jsDelivr 引入：`https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js`；备用镜像 cdnjs。
- 每张图配：标题、单位标注、数据基期、来源角标；图表容器桌面/移动端都要占满视口宽度（避免双栏 inline-block 在窄屏不堆叠导致空图）。
- 深色研报风格或浅色专业风格皆可，但全站配色统一、正文对比度达标；避免大面积紫/靛配色（除非用户指定）。

## 3. 交互（原生 JS）

- 目录跳转、折叠面板（争议/研究过程）、章节内图表懒渲染，均用原生 JS 实现，不用框架。
- 图表在窄屏下适配：媒体查询内让容器宽度 100%，图表 resize。

## 4. 自检与交付

- 交付前运行 `<html-skill-dir>/scripts/shot.py index.html`，Read 桌面（1440×900）与移动（390×844）截图核对：无 console 错误、图表渲染正常、窄屏不空图、文字不溢出。
- 有问题先改原文件再重跑 shot.py；通过后把 `index.html` 用 `present_files` 交付，并说明打开方式与数据时效。
